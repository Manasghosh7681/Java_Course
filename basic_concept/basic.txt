// What is a class ?
/*
A class is a blueprint or template that defines the properties and behavior of an object.
*/


// What is an Object ?
/*
An object is an instance of a class.
It contains actual values for the properties and can perform the behavior defined by the class.
*/


// What is public static void main(String args[]) ?

/*
main() method is public because the JVM needs to access and call it from outside the class.
*/

/*
main() method is static because the JVM can call it without creating an object of the class.
*/

/*
main() method is void because it does not return any value to the JVM.
*/

/*
String args[] is used to receive command-line arguments.
Command-line arguments are received as String values.

args[] is an array, so it can store multiple command-line arguments.
*/


// How does a Java program execute ?

/*
Java source code is first compiled using the javac compiler.

.java file
    ↓
javac compiler
    ↓
.class file (Bytecode)
    ↓
JVM
    ↓
Machine Code
    ↓
Program Execution
*/


/*-------------------------------------Variable--------------------------------------------------*/

// What is a variable ?

/*
A variable is a named memory location used to store a value.

The value of a variable can be changed during program execution,
unless the variable is declared as final.
*/


/*
There are 3 types of variables:

1. Local Variable
A variable declared inside a method, constructor, or block is called a local variable.

It can be accessed only within the method, constructor, or block
where it is declared.


2. Instance Variable
A variable declared inside a class but outside a method, constructor, or block
is called an instance variable.

It belongs to an object.
Each object has its own copy of an instance variable.


3. Static Variable
A variable declared inside a class but outside a method, constructor, or block
using the static keyword is called a static variable.

It belongs to the class rather than an individual object.

Only one copy of a static variable is created for a class,
and all objects share that variable.
*/


/*-----------------------------------------Constant---------------------------------------------*/

// What is a constant ?

/*
A constant is a variable whose value cannot be changed after it has been assigned.

In Java, a constant is generally created using the final keyword.

It is not necessary to assign the value at the time of declaration.

But the final variable must be assigned a value before it is used.
*/

Example:

final int a;

a = 10;


// a = 20;  // Error


/*-----------------------------------------Datatype----------------------------------------------*/

// What is a Data Type ?

/*
A data type defines what type of value a variable can store.

There are 8 primitive data types in Java.
*/


/*
1. byte     | Size: 1 byte  | Default value: 0
2. short    | Size: 2 bytes | Default value: 0
3. int      | Size: 4 bytes | Default value: 0
4. long     | Size: 8 bytes | Default value: 0L
5. float    | Size: 4 bytes | Default value: 0.0f
6. double   | Size: 8 bytes | Default value: 0.0d
7. char     | Size: 2 bytes | Default value: '\u0000'
8. boolean  | Size: JVM-dependent | Default value: false
*/


/*
Important:

The default values above apply to instance and static variables.

Local variables do NOT get default values.
A local variable must be initialized before it is used.
*/


/*-------------------------------------Wrapper Class-----------------------------------------------*/

// What is a Wrapper Class ?

/*
Wrapper classes are classes that provide object representations of primitive data types.

Primitive Data Type       Wrapper Class
===================       ==============
byte                      Byte
short                     Short
int                       Integer
long                      Long
float                     Float
double                    Double
char                      Character
boolean                   Boolean
*/


/*
There are two related concepts:

1. Autoboxing
The automatic conversion of a primitive data type into its corresponding wrapper object
is called autoboxing.


Example:

int a = 10;

Integer obj = Integer.valueOf(a);

Integer obj2 = a;       // Autoboxing
*/


/*
2. Unboxing
The automatic conversion of a wrapper object into its corresponding primitive data type
is called unboxing.


Example:

Integer obj = 10;

int pri = obj;          // Unboxing
*/


/*---------------------------------------Type Conversion---------------------------------------------*/

/*
There are two types of type conversion:

1. Widening
Converting a smaller data type into a larger compatible data type.

Example:

int a = 10;
long b = a;
*/


/*
2. Narrowing
Converting a larger data type into a smaller data type.

Explicit type casting is required.

Example:

float a = 20.0f;
int b = (int) a;
*/


/*---------------------------------Operator------------------------------------------------*/

/*
An operator is a symbol that is used to perform an operation on one or more operands.

Types of operators:

1. Arithmetic Operator
   (+, -, *, /, %)

2. Relational Operator
   (<, >, <=, >=, ==, !=)

3. Logical Operator
   (&&, ||, !)

4. Assignment Operator
   (=, +=, -=, *=, /=, %=)

5. Unary Operator
   (+, -, ++, --, !)

6. Ternary Operator
   (?:)

7. Bitwise Operator
   (&, |, ^, ~, >>, <<, >>>)
*/

/*--------------------------------------Methods---------------------------------------------*/

/*
A method is a block of code declared inside a class
that performs a specific task.
*/


/*
Method Declaration:

access modifier
return type
method name
parameters
*/


Example:

public void methodName(int x, int y) {

}


/*--------------------------------------Types of Methods-------------------------------------*/

/*
1. Instance Method

Example:

public void display() {

}

An instance method is associated with an object.

It can be called using an object:

ObjectName.display();
*/


/*
2. Static Method

Example:

public static void display() {

}

A static method belongs to the class.

It can be called using the class name:

ClassName.display();

A static method cannot directly access instance variables
or instance methods.
*/


/*
3. Final Method

Example:

public final void display() {

}

If a method is declared final, it cannot be overridden by a child class.
*/


/*
4. Abstract Method

Example:

public abstract void display();

An abstract method does not have a method body.

It must be declared inside an abstract class or interface.

The child class must provide the implementation
of the abstract method unless the child class is also abstract.
*/


/*-----------------------------------Variable Length Argument--------------------------------*/

/*
A variable-length argument (varargs) allows a method to accept
zero or more arguments of the same data type.

Syntax:

public void add(int... a) {

    int res = 0;

    for (int arg : a) {
        res += arg;
    }

    System.out.println(res);
}
*/


Example:

add(1);

add(1, 2);

add(1, 2, 3);

add(1, 2, 3, 4);
