/*-------------------------------------------Access Modifier---------------------------------------*/

/*
There are 4 access levels in Java:

1. private
2. public
3. protected
4. default
*/


/*-------------------------------------------private---------------------------------------*/

/*
private members can be accessed only inside the same class.
*/

class Student {

    private int marks = 90;

    public void display() {
        System.out.println(marks);     // Accessible
    }
}


/*-------------------------------------------public---------------------------------------*/

/*
public members can be accessed from anywhere,
provided the class itself is accessible.
*/


/*-------------------------------------------protected---------------------------------------*/

/*
protected members can be accessed:

1. Inside the same class
2. Inside the same package
3. Inside a subclass in another package
*/


/*-------------------------------------------default---------------------------------------*/

/*
If no access modifier is specified,
the member has default (package-private) access.

Default members can be accessed only within the same package.
*/


/*
Example of default access:

File: Student.java

package college;

public class Student {

    int marks = 90;       // default access
}
*/


/*
File: Main.java

package college;

public class Main {

    public static void main(String[] args) {

        Student s = new Student();

        System.out.println(s.marks);    // Accessible
    }
}
*/


/*
But from another package:

package office;

import college.Student;

public class Main {

    public static void main(String[] args) {

        Student s = new Student();

        System.out.println(s.marks);    // ❌ Cannot access
    }
}

Reason:

marks has default access,
and Main belongs to a different package.
*/


/*----------------------------Packages------------------------------*/

/*
A package in Java is a group of related classes, interfaces,
and other types.

Packages are used to organize code and avoid naming conflicts.
*/


/*
There are two common types of packages:

1. Built-in Packages
2. User-defined Packages
*/


/*--------------------------------Built-in Packages--------------------------------*/

/*
Built-in packages are packages provided by Java.

Examples:

java.lang
java.util
java.io
java.sql
*/


/*--------------------------------User-defined Packages--------------------------------*/

/*
User-defined packages are packages created by the programmer
to organize their own classes and interfaces.
*/


/*--------------------------------Creating a Package--------------------------------*/

/*
Syntax:

package packageName;


Example:

package student;
*/


/*--------------------------------Using a Package--------------------------------*/

/*
A class from another package can be imported using:

import packageName.ClassName;


Example:

import student.Student;
*/


/*--------------------------------Fully Qualified Name--------------------------------*/

/*
A Fully Qualified Name (FQN) consists of:

Package name + Class name


Example:

student.Student


It can be used without an import statement.

Example:

public class Main {

    public static void main(String[] args) {

        student.Student s = new student.Student();
    }
}
*/


/*--------------------------------Package Naming Convention--------------------------------*/

/*
Package names are generally written in lowercase.

Examples:

com.company.project
com.company.project.service
com.company.project.model
*/


/*--------------------------------Static Import--------------------------------*/

/*
Static import is used to import static members
of another class.

Example:

import static java.lang.Math.PI;


Then we can directly use:

System.out.println(PI);


Instead of:

System.out.println(Math.PI);
*/
