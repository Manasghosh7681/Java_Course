/*---------------------------Object-Oriented Programming-------------------------------*/

/*
1. Class

A class is a blueprint or template that defines the properties and behavior of an object.

Example:

class Vehicle {

    float speed;
    String color;

    public void start() {
    }

    public void end() {
    }
}
*/


/*
2. Object

An object is an instance of a class.
It contains actual values for the properties and can perform the behavior
defined by the class.

Example:

Vehicle v1 = new Vehicle();

v1.speed = 190;
v1.color = "Black";

v1.start();
v1.end();
*/


/*
3. Encapsulation

Encapsulation is the process of wrapping data members and methods
into a single unit and controlling access to the data.

Example:

In a banking application, a user may be allowed to update their KYC,
but they should not be allowed to directly change their account balance.

The balance can be kept private and accessed through methods
that control how the balance is updated.

This is an example of encapsulation.
*/


class Bank {

    String name;

    private float balance = 0;

    public void updateName(String name) {
        this.name = name;
    }

    public void addBalance(float amount) {
        this.balance += amount;
    }

    public float getBalance() {
        return this.balance;
    }
}


class Main {

    public static void main(String args[]) {

        Bank b1 = new Bank();

        b1.updateName("Manas Ghosh");

        System.out.println("Name: " + b1.name);

        b1.addBalance(1000);

        System.out.println("Balance: " + b1.getBalance());
    }
}


/*
4. Abstraction

Abstraction is the process of hiding implementation details
and showing only the essential features to the user.

Example:

When we press the power button on a TV remote,
the TV turns on.

We do not need to know how the remote internally communicates
with the TV.

This is an example of abstraction.
*/


/*
5. Polymorphism

Polymorphism means "many forms".

There are two types of polymorphism in Java:

    i. Runtime Polymorphism
    ii. Compile-time Polymorphism
*/


/*
i. Runtime Polymorphism

Runtime polymorphism is achieved through method overriding.

Method overriding occurs when a child class provides its own implementation
of a method that is already defined in the parent class.

The method must have the same method signature.

Example:
*/


class A {

    public void show() {
        System.out.println("A");
    }
}


class B extends A {

    @Override
    public void show() {
        System.out.println("B");
    }

    public static void main(String args[]) {

        B b1 = new B();

        b1.show();       // Output: B
    }
}


/*
ii. Compile-time Polymorphism

Compile-time polymorphism is achieved through method overloading.

Method overloading occurs when multiple methods have the same name
but different parameter lists.

Example:
*/


class Calculator {

    public void add(int a) {
        int res = a + 100;
    }

    public void add(int a, int b) {
        int res = a + b;
    }

    public void add(float a, float b, float c) {
        float res = a + b + c;
    }
}


/*
6. Inheritance

Inheritance is the process by which a child class acquires
the properties and behavior of a parent class.

Inheritance is achieved using the extends keyword.

Types of inheritance supported through Java classes:

    i. Single Inheritance
    ii. Multilevel Inheritance
    iii. Hierarchical Inheritance


i. Single Inheritance

One child class extends one parent class.


ii. Multilevel Inheritance

One child class extends a parent class,
and that parent class extends another parent class.

Example:

A
↓
B
↓
C


iii. Hierarchical Inheritance

Multiple child classes extend one parent class.

Example:

        A
       / \
      B   C
*/


/*
Note:

Java classes do not support multiple inheritance.

For example:

class C extends A, B {

}

This is not allowed in Java.

One reason is the Diamond Problem.

However, Java supports multiple inheritance of type through interfaces.

A class can implement multiple interfaces.
*/


/*
Diamond Problem:

Suppose:

        A
       / \
      B   C
       \ /
        D

If both B and C contain the same method,
D would have ambiguity about which implementation to use.

This is one reason Java does not allow multiple inheritance
through classes.
*/


/*-------------------------------------------Upcasting---------------------------------------*/

/*
Upcasting is the process of assigning a child class object
to a parent class reference.

Syntax:

Parent reference = new Child();

Example:
*/


class Animal {

    public void show() {
        System.out.println("Animal");
    }

    public void eat() {
        System.out.println("Animal eat");
    }
}


class Dog extends Animal {

    @Override
    public void eat() {
        System.out.println("Dog eat");
    }

    public void bark() {
        System.out.println("Dog bark");
    }
}


class Test {

    public static void main(String args[]) {

        Animal a = new Dog();      // Upcasting

        a.show();                 // Animal
        a.eat();                  // Dog eat
    }
}


/*
In upcasting:

Animal a = new Dog();

The reference type is Animal,
so we can directly access only the methods available in Animal.

However, if a method is overridden in Dog,
the Dog implementation is executed at runtime.

Therefore:

a.eat();

calls:

Dog's eat()
*/


/*-------------------------------------------Downcasting---------------------------------------*/

/*
Downcasting is the process of converting a parent class reference
into a child class reference.

Example:
*/


class Animal {

    public void show() {
        System.out.println("Animal");
    }

    public void eat() {
        System.out.println("Animal eat");
    }
}


class Dog extends Animal {

    @Override
    public void eat() {
        System.out.println("Dog eat");
    }

    public void bark() {
        System.out.println("Dog bark");
    }
}


class Test {

    public static void main(String args[]) {

        Animal a = new Dog();      // Upcasting

        a.show();                 // Animal
        a.eat();                  // Dog eat

        Dog d = (Dog) a;          // Downcasting

        d.show();                 // Animal
        d.eat();                  // Dog eat
        d.bark();                 // Dog bark
    }
}
